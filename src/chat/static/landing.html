Kaya

A home lab of AI agents that work for me

What started as a simple chatbot quickly became much more.

Kaya is what I call the ecosystem I have built at home: a chatbot for my friends, an assistant I talk to from my phone, agents that turn ideas into code and fix their own bugs, and a set of small scouts that tell me when something is worth knowing. Everything runs on my own hardware.

Built by Gustavo Abreu, AI engineer and forward deployed engineer.

Details +

Idea pipeline agent

How it works

  • A planning agent maps the idea to the right repository and asks its questions on WhatsApp

  • A QA agent grades it, runs up to three automatic fix rounds, and opens the pull request for my review
  • A pull request that brings in a new third-party GitHub repository has it checked for the signs of a fake project first, and one WhatsApp a day lists what has waited on me for more than a day

Measured, not assumed. Changes to the group chat are checked against a test set before they go live; when a fine-tuned model did not beat a stock one, the stock one won.
